# Welcome to Feedfinder2

Feedfinder2 is a modern Python library for discovering RSS, Atom, and JSON feeds from websites. It's a complete rewrite of [dfm/feedfinder2](https://github.com/dfm/feedfinder2) with async support, concurrent requests, and enhanced feed format detection.

## Quick Example

<CodeGroup>
```python Synchronous API
from feedfinder2 import find_feeds

feeds = find_feeds("https://xkcd.com")
print(feeds)
# ['https://xkcd.com/atom.xml', 'https://xkcd.com/rss.xml']
```

```python Async API
import asyncio
from feedfinder2 import find_feeds_async

async def discover():
    feeds = await find_feeds_async("https://xkcd.com")
    return feeds

feeds = asyncio.run(discover())
print(feeds)
```
</CodeGroup>
