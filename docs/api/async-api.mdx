# Async API

The async API provides significant performance improvements through concurrent HTTP requests.

## find_feeds_async()

Discover feed URLs from a website asynchronously with concurrent requests.

```python
from feedfinder2 import find_feeds_async, FeedFinderConfig

feeds = await find_feeds_async(
    url="https://example.com",
    config=None
)
```

### Parameters

<ParamField path="url" type="string" required>
  The website URL to search for feeds
</ParamField>

<ParamField path="config" type="FeedFinderConfig" default="None">
  Configuration object. If `None`, uses default configuration.

  See [Configuration](/api/configuration) for all available options.
</ParamField>

### Returns

<ResponseField name="feeds" type="List[str]">
  List of discovered feed URLs, sorted by relevance (highest priority first)
</ResponseField>

Returns an empty list if no feeds are found or if an error occurs.

### Example

```python
import asyncio
from feedfinder2 import find_feeds_async, FeedFinderConfig

async def discover():
    # Simple usage
    feeds = await find_feeds_async("https://xkcd.com")

    # With configuration
    config = FeedFinderConfig(
        timeout=10.0,
        max_concurrent_requests=20,
        check_all=True
    )
    feeds = await find_feeds_async("https://example.com", config)

    return feeds

feeds = asyncio.run(discover())
```

## Concurrent Discovery

Process multiple URLs in parallel:

```python
import asyncio
from feedfinder2 import find_feeds_async, FeedFinderConfig

async def discover_many(urls):
    config = FeedFinderConfig(max_concurrent_requests=20)

    # All URLs processed concurrently
    results = await asyncio.gather(
        *[find_feeds_async(url, config) for url in urls],
        return_exceptions=True
    )

    return results

urls = ["https://blog1.com", "https://blog2.com", "https://blog3.com"]
results = asyncio.run(discover_many(urls))
```

## Performance Benefits

### Single URL Discovery

For a single URL with `check_all=True`:

- **Sync API**: 15.0 seconds (sequential requests)
- **Async API**: 3.5 seconds (concurrent requests)
- **Speedup**: 4.3x faster

### Multiple URL Discovery

For 5 URLs in parallel:

- **Sync API**: 50.0 seconds (one at a time)
- **Async API**: 6.0 seconds (all concurrent)
- **Speedup**: 8.3x faster

## Discovery Process

The async function uses concurrent requests for maximum performance:

1. **Direct Check**: Tests if the URL itself is a feed
2. **Link Tags**: Parses `<link rel="alternate">` tags, validates all concurrently
3. **Anchor Tags**: Finds feed-like links, validates all concurrently
4. **Smart Guessing**: Tries common patterns, validates all concurrently

With `check_all=False` (default), stops after finding feeds. With `check_all=True`, tries all methods.

## Concurrency Control

The async API uses semaphores to limit concurrent requests:

```python
config = FeedFinderConfig(
    max_concurrent_requests=15,  # Max 15 concurrent HTTP requests
    max_connections=100,          # Max 100 total connections
)
```

This prevents overwhelming servers and ensures stable performance.

## Error Handling

Same graceful error handling as sync API:

- **Network errors**: Returns empty list, logs debug message
- **Timeouts**: Retries with exponential backoff, then returns empty list
- **Invalid URLs**: Returns empty list

Errors are collected per-URL, so one failing URL doesn't stop others in parallel discovery.

## Best Practices

<AccordionGroup>
  <Accordion title="Use for new code">
    The async API is recommended for all new code. It provides better performance and is production-ready.
  </Accordion>

  <Accordion title="Configure concurrency">
    Adjust `max_concurrent_requests` based on your use case:
    - Low (5-10): Conservative, good for rate-limited sites
    - Medium (15-20): Default, balanced performance
    - High (30-50): Maximum speed, use carefully
  </Accordion>

  <Accordion title="Handle exceptions">
    When processing multiple URLs, use `return_exceptions=True`:

    ```python
    results = await asyncio.gather(
        *[find_feeds_async(url) for url in urls],
        return_exceptions=True  # Don't fail on single error
    )
    ```
  </Accordion>

  <Accordion title="Set appropriate timeouts">
    Balance between reliability and speed:
    - Fast validation: 3-5 seconds
    - Standard discovery: 10 seconds (default)
    - Thorough search: 20+ seconds
  </Accordion>
</AccordionGroup>
