# Benchmarking

Measure feedfinder2 performance with your own URLs and use cases.

## Running the Benchmark Script

```bash
uv run python benchmark.py
```

This runs comprehensive benchmarks comparing:
- Synchronous API (sequential)
- Async API (sequential, one at a time)
- Async API (concurrent, all at once)

    "https://your-blog-1.com",

    "https://your-blog-3.com",

Then run:
```bash

```

### Quick Performance Test

```python
import time
from feedfinder2 import find_feeds, find_feeds_async
import asyncio

# Sync
start = time.time()
feeds_sync = find_feeds("https://xkcd.com", check_all=True)
sync_time = time.time() - start

# Async
async def test_async():
    start = time.time()
    feeds = await find_feeds_async("https://xkcd.com",
                                    FeedFinderConfig(check_all=True))
    return time.time() - start, feeds

async_time, feeds_async = asyncio.run(test_async())

print(f"Sync: {sync_time:.2f}s")
print(f"Async: {async_time:.2f}s")
print(f"Speedup: {sync_time / async_time:.2f}x")
```

## Understanding Performance

### What Affects Performance

<AccordionGroup>
  <Accordion title="Number of URLs to check">
    More potential feed URLs = longer discovery time.

    **Optimization**: Use `max_urls_to_try` to limit guessing.
  </Accordion>

  <Accordion title="check_all setting">
    - `check_all=False`: Stops after finding feeds (fast)
    - `check_all=True`: Tries all methods (slow but thorough)
  </Accordion>

  <Accordion title="Network latency">
    Server response times directly impact discovery speed.

    **Async helps most** when network latency is high.
  </Accordion>

  <Accordion title="Concurrency level">
    Higher concurrency = faster (up to a point).

    **Diminishing returns** after 20-30 concurrent requests.
  </Accordion>

  <Accordion title="Timeout settings">
    Longer timeouts = slower discovery if sites don't respond.

    **Balance**: Long enough for slow sites, short enough to fail fast.
  </Accordion>
</AccordionGroup>

### When Async Helps Most

**Maximum benefit**:
- Multiple URLs in parallel (8x+ speedup)
- Single URL with `check_all=True` (4x+ speedup)
- Slow/distant servers (network latency amortized)

**Minimal benefit**:
- Single URL with feeds in link tags
- Fast local servers
- Very strict timeout settings

## Performance Tuning

### For Fastest Results

```python
config = FeedFinderConfig(
    timeout=3.0,
    check_all=False,
    max_urls_to_try=15,
    max_retries=1,
    max_concurrent_requests=30
)
```

### For Most Thorough Results

```python
config = FeedFinderConfig(
    timeout=20.0,
    check_all=True,
    max_retries=5,
    max_concurrent_requests=15
)
```

### Balanced (Recommended)

```python
config = FeedFinderConfig(
    timeout=10.0,
    check_all=False,
    max_retries=3,
    max_concurrent_requests=15
)
```
