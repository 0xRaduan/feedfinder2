# Installation

Feedfinder2 requires Python 3.10 or higher.

<Note>
This is a fork not yet published to PyPI. Install from GitHub using the methods below.
</Note>

## With uv (Recommended)

```bash
uv add "feedfinder2 @ git+https://github.com/0xRaduan/feedfinder2.git"
```

Or add to your `pyproject.toml`:

```toml
dependencies = [
    "feedfinder2 @ git+https://github.com/0xRaduan/feedfinder2.git",
]
```

## With pip

```bash
pip install git+https://github.com/0xRaduan/feedfinder2.git
```

Or in `requirements.txt`:

```
feedfinder2 @ git+https://github.com/0xRaduan/feedfinder2.git
```

## From Source

```bash
git clone https://github.com/0xRaduan/feedfinder2.git
cd feedfinder2
uv sync
```

## Verify Installation

```python
import feedfinder2

print(feedfinder2.__version__)
# Output: 0.1.0
```

## Dependencies

Feedfinder2 automatically installs:

- **beautifulsoup4** - HTML parsing
- **lxml** - Fast XML parsing
- **requests** - Synchronous HTTP requests
- **httpx** - Async HTTP requests
- **six** - Python 2/3 compatibility utilities

All dependencies are pinned to stable versions and regularly updated.

## Development Installation

For contributing or running tests:

```bash
git clone https://github.com/0xRaduan/feedfinder2.git
cd feedfinder2

# Install with test dependencies
uv sync --group test

# Run tests
uv run pytest -v

# Run benchmarks
uv run python benchmark.py
```
